01

Paleta de color

Definida como variables CSS en :root. Toda la web se apoya en siete colores — dos neutros de acento y cinco de base — sin colores "sueltos" fuera del sistema.

Verde

--green: #b7cd02

Acento principal: títulos destacados, botones primarios, hover states, iconografía.

Negro

--black: #0a0a0a

Fondo base de la mayoría de las secciones.

Negro cálido

--dark: #111111

Variante de fondo para tarjetas y superficies elevadas.

Crema

--cream: #ece7dc

Acento textural (franja rasgada entre secciones).

Crema 2

--cream-2: #e4dfd2

Variante de crema para detalles de textura.

Blanco

--white: #ffffff

Texto principal sobre fondo oscuro.

Gris

--grey: #b8b8b8

Texto secundario: descripciones, subtítulos, placeholders.

04

Botones

Dos variantes sobre una base compartida (.btn): sólido para la acción principal, contorno para acciones secundarias. Ambos suben 3px al pasar el mouse.

.btn.btn--primary — background:var(--green); color:#101000 · .btn.btn--outline — border 1px solid var(--green)

08

Sistema responsive

Mobile-first en la composición visual, pero implementado con media queries "desktop-down". Breakpoints reales usados en el archivo, de mayor a menor.

≤ 1210px
Ajustes finos de tablet grande (corona de "Quiénes Somos", grilla de materiales)
≤ 1024px
Menú hamburguesa reemplaza la navegación horizontal
≤ 900px
Trabajos Realizados pasa a columna única
≤ 768px
Fondos de sección: control independiente de posición/tamaño
≤ 640px
Layout mobile completo: navegación, tipografía y composición apilada
≤ 420px
Ajustes finales para los celulares más angostos
09

Motion & efectos

Animación con GSAP + ScrollTrigger (reveals al hacer scroll) y Lenis (scroll suave), respetando prefers-reduced-motion en toda la web.

Hero — entrada de título y fondoGSAP timeline · stagger .15s
Reveals de secciónScrollTrigger · fade + translateY
Flip cards (Quiénes Somos)transform: rotateY · perspective:1200px
Botones (hover)transform: translateY(-3px) · .35s ease
Tarjetas de curso (hover)transform: translateY(-8px) · border-color · .4s ease
Scroll suave globalLenis
Accesibilidad@media (prefers-reduced-motion: reduce) → animaciones desactivadas
